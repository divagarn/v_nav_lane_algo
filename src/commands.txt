RANSAC is gpu or cpu — both run the same RANSAC algorithm, just GPU (CUDA) vs CPU (NumPy). Only segment is the new non-RANSAC one.


ground_filter_device:=gpu   # RANSAC on GPU/CUDA (default - same as not passing the arg at all)
ground_filter_device:=cpu   # RANSAC on CPU (NumPy) - same algorithm, slower, no GPU dependency
So for either sim or real, just add (or omit, since gpu is already the default):


ros2 launch buggy_mapping localize.launch.py map_name:=my_map2 ground_filter_device:=gpu        # sim, RANSAC/GPU
ros2 launch buggy_mapping real_localize.launch.py feedback_port:=/dev/ttyUSB0 rviz:=true ground_filter:=true map_name:=my_map2 ground_filter_device:=gpu   # real, RANSAC/GPU
