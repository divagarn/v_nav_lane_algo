One thing to keep in mind when you increase it: lane_lookahead (default 12.0) is how far /suggested_lane itself extends — the bent-corridor fix only bends up to wherever that path reaches. If you push ahead_zone_length_m close to or past lane_lookahead, the zone's far end will run past the available path and fall back to extending straight in the last segment's direction (the short-path handling from the bend fix), so for a meaningfully longer zone you'll probably want to raise lane_lookahead too, e.g. lane_lookahead:=15.0 alongside ahead_zone_length_m:=8.0.
